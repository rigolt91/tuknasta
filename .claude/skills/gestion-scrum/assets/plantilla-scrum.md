## 4. Ceremonias

Ver `plantillas-ceremonias.md` para el formato reutilizable de cada ceremonia. Resumen de cuándo usar cada una:

- **Sprint Planning**: al inicio de cada sprint, para seleccionar y comprometer el trabajo.
- **Daily Standup**: cada día, breve (15 min), para sincronizar avance y bloqueos.
- **Sprint Review**: al cierre del sprint, para mostrar lo construido y recoger feedback.
- **Retrospectiva**: al cierre del sprint (después del review), para mejorar el proceso del equipo.
