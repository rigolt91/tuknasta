# Plantillas de Ceremonias Scrum

Plantillas reutilizables para cada sprint del proyecto. No están llenas de contenido específico — cópialas y complétalas en cada ceremonia real.

---

## Sprint Planning

**Duración sugerida:** 1-2 horas por semana de sprint (ej. 1-2h para sprint de 1 semana).

**Agenda:**
1. Revisar el Sprint Goal propuesto — ¿sigue siendo válido?
2. Revisar historias candidatas del backlog (de mayor a menor prioridad)
3. Para cada historia: ¿está claro el criterio de aceptación? ¿hay dependencias sin resolver?
4. Confirmar el compromiso del sprint (historias + puntos totales)
5. Identificar riesgos u obstáculos previsibles para este sprint

**Preguntas guía:**
- ¿Qué historias son imprescindibles para cumplir el Sprint Goal?
- ¿Hay algo bloqueado por una decisión externa (cliente, integración de terceros)?

---

## Daily Standup

**Duración sugerida:** 15 minutos, mismo horario cada día.

**Formato (por persona, o por uno mismo si se trabaja solo):**
1. ¿Qué hice ayer / desde la última actualización?
2. ¿Qué voy a hacer hoy?
3. ¿Hay algún bloqueo?

*Nota: si el equipo es de una sola persona, este ritual sigue siendo útil como checkpoint de progreso y detección temprana de bloqueos — no lo descartes por trabajar en solitario.*

---

## Sprint Review

**Duración sugerida:** 30-60 minutos al cierre del sprint.

**Agenda:**
1. Mostrar lo construido durante el sprint (demo funcional, no solo describir)
2. Comparar contra el Sprint Goal — ¿se cumplió, parcialmente, o no?
3. Recoger feedback (del cliente si está presente, o autoevaluación si no)
4. Actualizar el backlog con lo que surja del feedback

---

## Retrospectiva

**Duración sugerida:** 30-45 minutos, después del Sprint Review.

**Formato sugerido: Start / Stop / Continue**

| Empezar a hacer | Dejar de hacer | Seguir haciendo |
|-------------------|-------------------|-------------------|
| [idea nueva] | [algo que no funcionó] | [algo que sí funcionó] |

**Cierre:** elegir máximo 1-2 acciones concretas para el siguiente sprint — una retrospectiva sin acciones de seguimiento no cambia nada.
